\# Master Sharli Barber Shop Web Platform



Master Sharli Barber Shop Web Platform is a premium barber shop website and smart appointment booking system.



The system will be built with React and Java Spring Boot. Customers will be able to view services, explore the gallery, and book appointments online. After an appointment is created, the system will use n8n automation to send WhatsApp confirmation messages to customers and appointment notifications to the shop owner.



\## Technologies



\- Frontend: React

\- Backend: Java Spring Boot

\- Database: PostgreSQL or MySQL

\- Automation: n8n

\- Notification: WhatsApp integration

\- Future Feature: AI-assisted appointment support



\## Main Features



\- Premium landing page

\- Services section

\- Gallery section

\- Online appointment booking

\- Admin appointment management

\- WhatsApp appointment confirmation

\- n8n automation workflow

\- Future AI assistant
